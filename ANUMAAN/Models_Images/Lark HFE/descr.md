# Lark HFE (Heavy Fuel Engine) Specifications

## General Description
The Lark HFE (Heavy Fuel Engine) is a specialized 150-hp class aviation propulsion powerplant developed by Anhui Haery Aviation Power under the China Academy of Aerospace Aerodynamics (CAAA / CASC). Designed specifically as a high-efficiency heavy-fuel replacement for MALE unmanned aerial vehicles, it is the premier power unit for the CH-4 (Rainbow-4) combat reconnaissance drone.

## Technical Specifications
| Specification | Value |
| :--- | :--- |
| **Engine Type** | 4-Cylinder, 4-Stroke Liquid-Cooled Heavy Fuel Piston Engine |
| **Aspiration** | Exhaust Turbocharged with Charge Air Intercooler |
| **Maximum Power** | 150 HP (110 kW) |
| **Dry Weight** | 98 kg |
| **Fuel System** | High-Pressure Common Rail (HPCR) Diesel Injection |
| **Engine Control** | Full Authority Digital Electronic Control (FADEC) |
| **Fuel Compatibility** | Heavy Fuel: Aviation Kerosene (Jet A, Jet A-1, RP-3), Aviation Diesel |
| **Fuel Consumption Benefit** | ~20% lower specific fuel consumption compared to gasoline equivalent |
| **Time Before Overhaul (TBO)** | 2,000 Flight Hours |
| **Target Aircraft Integration** | CASC CH-4 (Rainbow-4) MALE UAV, Long-Endurance Tactical Drones |
| **Mission Endurance Impact** | Extends CH-4 flight endurance from 30 hours to 42+ hours |
