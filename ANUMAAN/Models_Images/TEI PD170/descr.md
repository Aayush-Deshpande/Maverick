# TEI-PD170 Turbodiesel Aviation Engine Specifications

## General Description
The TEI-PD170 is a state-of-the-art, 2.1-liter in-line 4-cylinder, four-stroke liquid-cooled turbodiesel aircraft engine developed by TUSAŞ Engine Industries (TEI). Specifically engineered for Medium Altitude Long Endurance (MALE) tactical unmanned aerial vehicles (UAVs), it serves as the indigenous propulsion system for the Bayraktar TB3, TAI ANKA, and TAI AKSUNGUR.

## Technical Specifications
| Specification | Value |
| :--- | :--- |
| **Engine Type** | In-line 4-Cylinder, 4-Stroke Turbodiesel |
| **Aspiration** | Two-Stage Sequential Turbocharged with Intercooler |
| **Displacement** | 2.1 Liters (2,100 cc) |
| **Max Takeoff Power** | 172 HP (±2 HP) @ 2,300 Propeller RPM |
| **Max Continuous Power** | 170 HP up to 20,000 ft; 130 HP @ 30,000 ft |
| **Service Ceiling** | 45,000 ft |
| **Critical Altitude** | 20,000 ft |
| **Dry Weight** | 162 kg (including dual turbochargers & intercooler system) |
| **Fuel Compatibility** | JP-8, Jet A-1, JP-5, EN 590 Aviation Diesel |
| **Fuel Supply System** | High-Pressure Common Rail (HPCR) Direct Diesel Injection |
| **Engine Management** | Dual Redundant FADEC / EECU (DO-178C / DO-254 Certifiable) |
| **Electrical Power Output** | 9 kW (Dual 2x 4.5 kW 28V DC Alternators) |
| **Time Between Overhauls (TBO)**| 3,600 Flight Hours |
| **Brake Specific Fuel Consumption (BSFC)** | 207 g/kWh (±3) @ MSL |
| **Target Aircraft** | Bayraktar TB3 UCAV, TAI Anka-S, TAI Aksungur |
