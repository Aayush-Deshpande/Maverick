### Issue 1: High-Speed Buffer Truncation of the 30-Minute Degradation Window
* **Issue Summary:** The 30-minute analysis window (`WINDOW_SIZES_SEC["long"] = 1800`) is starved of historical data because the underlying circular buffer only stores 6 minutes of frames.
* **Code Evidence:**
  * In `backend/server/engine_service.py` (Line 140):
    ```python
    self.score_buffer = ScoreBuffer(maxlen=7200)
    ```
  * In `backend/ml/trend_analyser.py` (Line 257):
    ```python
    WINDOW_SIZES_SEC = {
        "short":  2  * 60,  # 120s
        "medium": 10 * 60,  # 600s
        "long":   30 * 60,  # 1800s
    }
    ```
* **Root Cause:** At 20 Hz, 7,200 frames equal $7200 \times 0.05\text{ s} = 360.0\text{ seconds} = 6.0\text{ minutes}$. Because `ScoreBuffer` stores raw 20 Hz frames in a single uncompressed `collections.deque`, the oldest frames are discarded after 6 minutes.
* **Impact:** The `short` window (2 min) and `medium` window (up to 6 min) operate accurately, but the `long` window (designed for 30-minute slow injector coking or EGT drift) only ever evaluates the last 6 minutes of data.
* **Required Remediation:** Implement a **Dual-Rate Tiered Ring Buffer**:
  * Tier 1 (High-Rate): 20 Hz buffer holding 6,000 frames (5 minutes) for high-speed anomaly scoring and short-window fits.
  * Tier 2 (Downsampled): 1 Hz buffer holding 1,800 frames (30 minutes) populated by downsampling Tier 1 averages every second.
* **Verification Test:** Assert `len(tier2_buffer) >= 1800` after 30 minutes of simulated continuous flight.

### Issue 2: Asymmetric Single-Cylinder Subsystem Channel Mapping
* **Issue Summary:** `COMPONENT_CHANNELS` maps the `Cylinder_Head_Assembly` subsystem exclusively to `d_CHT_2`, and `Ignition_Harness` exclusively to `d_EGT_2`.
* **Code Evidence:**
  * In `backend/ml/trend_analyser.py` (Lines 216–223):
    ```python
    COMPONENT_CHANNELS: Dict[str, List[str]] = {
        "Cylinder_Head_Assembly": ["d_CHT_2"],          # Primary: CHT_2 residual
        "Lubrication_Oil_Circuit": ["d_OIL_PRESS"],     # Primary: oil pressure drop
        "Reduction_Gearbox": ["d_VIB_RMS"],             # Primary: vibration residual
        "Alternator_Bus": ["d_BUS_VOLTAGE"],             # Primary: bus voltage sag
        "Fuel_Injection_Rail": ["d_FUEL_FLOW"],          # Primary: fuel flow drop
        "Ignition_Harness": ["d_EGT_2"],                # Primary: EGT misfire runner
    }
    ```
* **Root Cause:** Hardcoded prototype mapping developed specifically around canonical Fault 01 (Cylinder #2 Overheat) and Fault 03 (Runner #2 Misfire).
* **Impact:** If a real-world thermal micro-drift develops on Cylinder #1, #3, or #4 (e.g. $+0.40^\circ\text{C}/\text{min}$), the whole-engine `__composite__` channel will detect the anomaly, but the specific `Cylinder_Head_Assembly` RUL estimate will report `inf` because `d_CHT_2` remained nominal.
* **Required Remediation:** Update `COMPONENT_CHANNELS` to scan all 4 cylinder channels dynamically:
  ```python
  COMPONENT_CHANNELS: Dict[str, List[str]] = {
      "Cylinder_Head_Assembly": ["d_CHT_1", "d_CHT_2", "d_CHT_3", "d_CHT_4"],
      "Lubrication_Oil_Circuit": ["d_OIL_PRESS", "d_OIL_TEMP"],
      "Reduction_Gearbox": ["d_VIB_RMS"],
      "Alternator_Bus": ["d_BUS_VOLTAGE"],
      "Fuel_Injection_Rail": ["d_FUEL_FLOW"],
      "Ignition_Harness": ["d_EGT_1", "d_EGT_2", "d_EGT_3", "d_EGT_4"],
  }
  ```
  In `_analyse_and_update()`, evaluate all channels for a component and select the channel with the **most severe degradation slope / lowest RUL**.
* **Verification Test:** Inject a $+0.35^\circ\text{C}/\text{min}$ drift on `CHT_3` and verify that `rul_estimates["Cylinder_Head_Assembly"]` correctly captures the degradation and reports a finite $p_{10}$ RUL.

### Issue 3: Power-Law Instantaneous Derivative Singularity at $t = 0$
* **Issue Summary:** When the Power-Law model $y = a t^b$ is selected, calculating the instantaneous drift rate at the first timestamp ($t_{\text{now}} = 0$) results in `0.0`, temporarily suppressing trend detection on the first evaluation tick.
* **Code Evidence:**
  * In `backend/ml/trend_analyser.py` (Lines 354–360):
    ```python
    else:  # power_law
        if t_now_min > 0:
            drift_rate = best_model.a * best_model.b * (
                t_now_min ** (best_model.b - 1.0))
        else:
            drift_rate = 0.0
    ```
* **Root Cause:** The analytical derivative $\frac{dy}{dt} = a b t^{b-1}$ has an arithmetic singularity at $t = 0$ when $b < 1$.
* **Impact:** For the very first analysis cycle after a sortie begins, a power-law trend evaluates `is_trending = False` until $t_{\text{now}} > 0$.
* **Required Remediation:** Replace analytical point evaluation with numerical forward difference:
  ```python
  dt_eval = 0.1  # 6 seconds in minutes
  drift_rate = (predict(t_now_min + dt_eval) - predict(t_now_min)) / dt_eval
  ```
* **Verification Test:** Assert that `drift_rate > 0` for a power-law model evaluated at $t_{\text{now}} = 0$.
