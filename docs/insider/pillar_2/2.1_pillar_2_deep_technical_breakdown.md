## 1. Purpose & Problem-Statement Mapping

### 1.1 The Exact Purpose of Pillar 2
Pillar 2 (**In-Flight Early Degradation Trending**) detects, isolates, and forecasts **sub-threshold mechanical, thermal, fluid, and electrical micro-drifts** while the engine's operating parameters remain entirely within nominal limits (the "green zone"). It projects these trends forward in time using statistical regression and physics thresholds to produce a **predictive Time-to-Breach (TTB)** before irreversible damage occurs.

### 1.2 DRDO Problem Statement (PS-26054) Mapping
In military Medium Altitude Long Endurance (MALE) UAV operations (such as the **TAPAS-BH-201** or **Rustom-II** on 18- to 30+ hour border surveillance sorties), propulsion availability is single-fault critical. A single 4-cylinder aero piston engine (Rotax 912 iS Sport) powers the airframe.

Pillar 2 directly implements the core requirement defined in DRDO PS-26054:
> *"A micro-leak in a cooling air baffle causes Cylinder #2 to increase at +0.38 °C every 10 minutes. While still in the green zone (112 °C vs 135 °C static limit), the Digital Twin flags the residual anomaly trend, predicting a critical breach in 42 minutes."*

```
CONVENTIONAL THRESHOLD MONITORING (REACTIVE):
   [Sensor: 105°C] ──► [Sensor: 118°C] ──► [Exceeds 135°C Limit!] ──► [ALARM RINGS!] ──► [Piston Seizes / Crash]
   * Zero predictive horizon. Warning fires when irreversible metallurgical damage has already started.

PILLAR 2 AI DIGITAL TWIN (PREDICTIVE TRENDING):
   [Sensor: 105°C] ──► [Drift Detected: +0.38°C/min Residual] ──► [TTB: 42 min to breach] ──► [Derate Throttle Directive]
   * Identifies micro-trends 30-60 min early. Advises pilot to lower RPM or switch FADEC Lane B, saving the UAV.
```

### 1.3 Why Early Degradation Trending is Necessary (Beyond Pillar 1)
* **Pillar 1 (Pre-Flight Certification & Static Limits):** Operates as a pre-mission gate and instantaneous boundary monitor. It catches hard limit breaches (for example, Cylinder Head Temperature exceeding 135.0 °C or Oil Pressure dropping below 2.0 bar).
* **The "Threshold Trap":** Aero-engine failures do not happen instantaneously. They develop over tens of minutes or hours:
  * A dry-sump scavenge pump slowly loses internal sealing, causing oil gallery pressure to decay by -0.02 bar every 10 minutes.
  * A cooling shroud elastomeric seal hardens in high-altitude sub-zero air, reducing airflow over Cylinder #2.
  * An injector nozzle accumulates fuel varnish, steadily leaning out Cylinder #1.
* **Why Static Alarms Fail:** Under conventional threshold monitoring, an alarm rings only when the parameter breaches the absolute limit. By the time Cylinder #2 reaches 135.1 °C, the cylinder head has warped, valve guides have distorted, or piston ring micro-welding has started. The engine seizes, and the UAV is lost.
* **Pillar 2 Solution:** Rather than monitoring raw values against static limits, Pillar 2 monitors the **rate-of-change (slope and trajectory) of normalized physics residuals (Delta = Actual - Expected)**. It flags the problem when Cylinder #2 is at 112 °C (23 °C below the limit), calculates that a thermal breach will occur in 42 minutes, and advises the ground station to reduce cruise RPM or initiate a Return-to-Base (RTB) vector.

### 3.2 Parameter Normalization Equations
In Stage 5 of `DetectionPipeline.process_frame()` (`backend/ml/detection_pipeline.py`), physical residuals `Delta = Actual - Expected` are converted into normalized degradation scores bounded in `[0.0, 1.0]`:

* `score_d_CHT_i = min(1.0, abs(Delta_CHT_i) / 15.0)`
* `score_d_EGT_i = min(1.0, abs(Delta_EGT_i) / 60.0)`
* `score_d_OIL_PRESS = min(1.0, abs(Delta_OIL_PRESS) / 2.0)`
* `score_d_OIL_TEMP = min(1.0, abs(Delta_OIL_TEMP) / 20.0)`
* `score_d_FUEL_FLOW = min(1.0, abs(Delta_FUEL_FLOW) / 6.0)`
* `score_d_MAP = min(1.0, abs(Delta_MAP) / 10.0)`
* `score_d_VIB_RMS = min(1.0, abs(Delta_VIB_RMS) / 2.5)`
* `score_d_BUS_VOLTAGE = min(1.0, abs(Delta_BUS_VOLTAGE) / 2.0)`

### 3.3 Historical Retention & Circular Buffer Mechanics
* **Ingestion Cadence:** Every 50 ms (20 Hz), Thread 1 appends `(timestamp_sec, composite_score, channel_scores_dict)` to `ScoreBuffer`.
* **Buffer Capacity:** `ScoreBuffer` is initialized with `maxlen = 7200` in `engine_service.py`, storing up to **6.0 minutes of uncompressed 20 Hz telemetry history** (7,200 * 0.05 s = 360 s).
* **Thread-Safe Snapshotting:** When `PrognosticsWorker` runs, it calls `ScoreBuffer.snapshot()` which acquires an internal `threading.Lock()` and copies the 7,200 tuples in < 0.5 ms, releasing the lock immediately to prevent telemetry jitter.
* **Timebase Construction:** Time is normalized relative to the oldest frame in the snapshot:
  `t_i = (timestamp_i - timestamp_0) / 60.0` [minutes]  
  `y_i = channel_scores.get(channel, composite_score)` [0.0 to 1.0]

## 4. Micro-Drift Detection Mechanism

### 4.1 Establishing the Dynamic Baseline
A major technical challenge in aero-engine prognostics is separating **pilot-commanded operating changes** (e.g., advancing throttle to climb) from **physical engine degradation**.

Pillar 2 solves this by using a **dynamic 1D thermodynamic physics shadow** (`RotaxThermoModel` in `backend/physics/thermo_model.py`):
1. The physics model continuously solves Otto-cycle differential equations every 50 ms given ambient altitude, OAT, true airspeed, and throttle position (TPS).
2. It generates theoretical baseline parameters: `CHT_expected(t)`, `EGT_expected(t)`, `MAP_expected(t)`, `OilPress_expected(t)`, `FuelFlow_expected(t)`.
3. Because the baseline dynamically tracks throttle and altitude changes, **normal flight maneuvers produce zero residual deviation (Delta approx 0)**.
4. Only unmodelled mechanical/thermal losses (such as baffle leakage or pump wear) cause the residual `Delta(t)` to grow over time.

```
                           MICRO-DRIFT SEPARATION PRINCIPLE
Throttle Advance / Climb:
   Actual CHT rises +15°C  ──►  Physics Model expects +15°C  ──►  Residual Delta = 0.0°C  ──►  NO DRIFT FLAGGED

Baffle Seal Leak / Contraction:
   Actual CHT rises +15°C  ──►  Physics Model expects 0.0°C   ──►  Residual Delta = +15.0°C ──►  DEGRADATION DETECTED
```

### 4.2 Distinguishing Micro-Drifts from Sensor Noise
To prevent false alarms from Gaussian transducer noise or turbulence jitter, Pillar 2 enforces three mathematical criteria in `DegradationTrendAnalyser.analyse()`:
1. **Goodness-of-Fit Gate (R^2 >= 0.55):** Random sensor noise has an R^2 approx 0.0. Only persistent, directional drift satisfies the minimum correlation threshold `MIN_R2 = 0.55`.
2. **Minimum Drift Rate Gate (Slope > 0.0002 / min):** Flat lines or minor thermal oscillations (< 0.012 / hour) are rejected as stationary noise.
3. **Observation Persistence:** A trend must persist across multiple 20-second analysis cycles and be confirmed over a multi-minute window before generating an advisory.

### 5.1 Window Selection Algorithm
In `DegradationTrendAnalyser.analyse()`:
1. Points are filtered for each window: `window_points = [(t, s) for t, s in points if current_t - t <= wsec]`.
2. All 3 regression models (Linear, Exponential, Power-Law) are fitted on each window subset.
3. The best model per window is chosen via AIC.
4. Across all candidate windows, the system selects the window that produces the **highest R^2 fit** that satisfies the trending criteria (`is_trending = True`).

## 6. Mathematical Trend Models & AIC Model Selection

Pillar 2 implements three candidate regression models in pure Python without external numerical libraries:

```
                                CANDIDATE DEGRADATION EQUATIONS
┌───────────────────┬───────────────────────────┬───────────────────────────────┬───────────────────────────────┐
│ Candidate Model   │ Mathematical Equation     │ Linearized Transform Form     │ Physical Degradation Context  │
├───────────────────┼───────────────────────────┼───────────────────────────────┼───────────────────────────────┤
│ 1. Linear         │ y(t) = a + b * t          │ y = a + b * t                 │ Constant-rate abrasive wear,  │
│                   │                           │ (Closed-form OLS)             │ steady oil pressure leaks.    │
├───────────────────┼───────────────────────────┼───────────────────────────────┼───────────────────────────────┤
│ 2. Exponential    │ y(t) = a * exp(b * t)     │ ln(y) = ln(a) + b * t         │ Thermal runaway, self-rein-   │
│                   │                           │ (Filtered for y > 1e-6)       │ forcing friction / blow-by.   │
├───────────────────┼───────────────────────────┼───────────────────────────────┼───────────────────────────────┤
│ 3. Power-Law      │ y(t) = a * (t ^ b)        │ ln(y) = ln(a) + b * ln(t)     │ Material fatigue, crack growth│
│                   │                           │ (Filtered for t > 0, y > 0)   │ Paris-Erdogan law dynamics.   │
└───────────────────┴───────────────────────────┴───────────────────────────────┴───────────────────────────────┘
```

### 6.1 Model Fitting Equations

#### 1. Linear Regression (Closed-Form Ordinary Least Squares)
Given `n` historical observations `(t_i, y_i)`:
* `b = (n * sum(t_i * y_i) - sum(t_i) * sum(y_i)) / (n * sum(t_i^2) - (sum(t_i))^2)`
* `a = (sum(y_i) - b * sum(t_i)) / n`
* `SSE_linear = sum((y_i - (a + b * t_i))^2)`
* `R^2 = 1.0 - (SSE / sum((y_i - mean_y)^2))`

#### 2. Exponential Model (Log-Linear Transformation)
Transforms `y = a * exp(b * t)` into `ln(y) = ln(a) + b * t`.
Fitting `(t_i, ln(y_i))` via OLS yields `(a_log, b)`:
* `a = exp(a_log)`
* `SSE_exponential = sum((y_i - a * exp(b * t_i))^2)`

#### 3. Power-Law Model (Log-Log Transformation)
Transforms `y = a * (t ^ b)` into `ln(y) = ln(a) + b * ln(t)`.
Fitting `(ln(t_i), ln(y_i))` via OLS yields `(a_log, b)`:
* `a = exp(a_log)`
* `SSE_power = sum((y_i - a * (t_i ^ b))^2)`

---

### 6.2 Akaike Information Criterion (AIC) Selection Formulation
In `backend/ml/trend_analyser.py`, candidate models within each window are evaluated using AIC:

`AIC = n * ln(SSE / n) + 2 * k`  
Where:
* `n` = Number of observation frames in the window
* `SSE` = Sum of Squared Errors on the actual physical scale: `sum((y_i - y_hat_i)^2)`
* `k = 2` = Number of estimated parameters (intercept `a` and rate `b`)

**Selection Rule:** The model with the **lowest AIC** is selected. If `SSE <= 0` or `n < k + 1`, AIC returns infinity.

## 7. Time-to-Breach (TTB) Prediction & Monte Carlo Uncertainty

### 7.1 Analytical Time-to-Breach Binary Search
Once the winning model is selected, Pillar 2 calculates the forward projection until the degradation curve intersects the subsystem failure threshold:

`Solve for t_breach such that y_hat(t_breach) = Threshold_fault`

```
Subsystem Thresholds (FAULT_THRESHOLD_SCORE):
• Cylinder Head (d_CHT_2):     0.75  (equivalent to +11.25 °C residual above physics baseline)
• Lubrication Oil (d_OIL_P):   0.80  (equivalent to -1.60 bar oil pressure drop)
• Reduction Gearbox (d_VIB):   0.70  (equivalent to +1.75 mm/s vibration residual)
• Alternator Bus (d_BUS_V):    0.72  (equivalent to -1.44 V DC bus sag)
• Fuel Injection (d_FUEL_F):   0.70  (equivalent to -4.20 L/hr fuel flow deficit)
• Ignition System (d_EGT_2):   0.70  (equivalent to -42.0 °C misfire runner drop)
```

**Binary Search Algorithm (`_time_to_breach`):**
1. If `current_score >= threshold`, return `TTB = 0.0 min` (already breached).
2. If the model slope is negative or flat (`predict(t_now + 1.0) <= predict(t_now)`), return `TTB = inf` (no upward degradation).
3. Perform 40 bisection iterations across an 8-hour search horizon `[t_now, t_now + 480.0 min]`:
   `t_mid = (t_lo + t_hi) / 2.0`  
   `If predict(t_mid) < threshold -> t_lo = t_mid, Else t_hi = t_mid`
4. Return `Delta_T = t_breach - t_now`.

│ Fitted Degradation Model│ ──► Model Parameters: a, b  |  Fit Quality: R^2, n_points
└─────────────────────────┘
             │
             ▼
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ Parameter Variance Formulation:                                                        │
│ • Slope Standard Error:   sigma_b = ((1.0 - R^2) / sqrt(n)) * 2.0                      │
│ • Intercept Uncertainty:  sigma_a = sigma_b * 0.30                                     │
└────────────────────────────────────────────────────────────────────────────────────────┘
             │
             ▼ (Sample 500 Iterations)
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ For i = 1 ... 500:                                                                     │
│   b_perturbed = b * (1.0 + Gaussian_Noise(mean=0, std=sigma_b))                        │
