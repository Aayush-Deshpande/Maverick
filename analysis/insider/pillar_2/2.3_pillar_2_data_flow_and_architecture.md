**Scope:** Complete End-to-End Execution Trace & Data Contract Flow for In-Flight Early Degradation Trending  
**Architectural Domain:** 2-Plane Cyber-Physical Architecture (Plane 1 Real-Time Loop to Plane 2 Decision Support)  

---

## 1. End-to-End Traced Pipeline Overview

The complete Pillar 2 operational pipeline follows a sequential 12-stage execution path:

```
[1. Real-Time Telemetry Generation / CAN Ingestion (20 Hz)]
                              │ (EnginePhysicalState: RPM, TPS, CHT1-4, EGT1-4, OilP, MAP, etc.)
                              ▼
[2. 1D Thermodynamic Physics Shadow (RotaxThermoModel)]
                              │ (Solves Otto cycle given Alt, OAT, TAS, TPS -> Expected State)
                              ▼
[3. Residual Vector Calculation & Divisor Normalization]
                              │ (Delta = Actual - Expected -> 14 normalized z-scores + composite)
                              ▼
[4. ScoreBuffer Ingestion (Thread 1 -> Circular Deque)]
                              │ (Appends timestamp, composite_score, channel_scores dict)
                              ▼
=================== THREAD BOUNDARY (20 Hz Loop to 20s Worker) ===================
                              │ (PrognosticsWorker acquires lock & takes buffer snapshot)
                              ▼
[5. Multi-Window Time-Series Slicing (DegradationTrendAnalyser)]
                              │ (Slices history into Short: 2m, Medium: 10m, Long: 30m subsets)
                              ▼
[6. Candidate Model Regression Fitting]
                              │ (Fits Linear OLS, Exponential Log-Linear, Power-Law Log-Log)
                              ▼
[7. Akaike Information Criterion (AIC) Model Selection]
                              │ (Evaluates AIC = n*ln(SSE/n) + 2k -> Selects minimum AIC model)
                              ▼
[8. Analytical Time-to-Breach Projection (TTB)]
                              │ (40-step binary search bisection to Subsystem Failure Threshold)
                              ▼
[9. Monte Carlo Probabilistic RUL Simulation]
                              │ (500 parameter perturbations -> Derives p10, p50, p90 bounds)
                              ▼
[10. Alert Level & Health Impact Assessment]
                              │ (Assigns NOMINAL, WATCH, WARNING, CRITICAL alert levels)
                              ▼
[11. Downstream State Packaging (EngineStateService)]
                              │ (Injects early_warning_trend into AnalyticsState & Unified State)
                              ▼
[12. WebSocket Broadcast & GCS Dashboard Rendering]
                              │ (FastAPI /ws/telemetry -> React DiagnosticCard & 3D HUD)
```

---

## 2. Step-by-Step Data Flow & Method Tracing

### Step 1: Real-Time Ingestion (Thread 1 — 20 Hz)
* **Caller:** `EngineStateService._run_loop()` in `backend/server/engine_service.py` ticking every 50 ms ($dt = 0.05\text{ s}$).
* **Action:** Calls `self.streamer.generate_frame()`, returning:
  * `actual: EnginePhysicalState` (27 parameters including `ENGINE_RPM`, `TPS`, `CHT_1..4`, `EGT_1..4`, `OIL_PRESS`, `MAP`, `ALTITUDE_FT`, `OAT_C`, `TAS_KNOTS`).
* **Source:** `backend/telemetry/can_streamer.py`.

---

### Step 2: 1D Thermodynamic Physics Baseline
* **Caller:** Stage 2 of `DetectionPipeline.process_frame()` in `backend/ml/detection_pipeline.py`.
* **Action:** Calls `RotaxThermoModel.compute_expected_state()`:
  * Inputs: `altitude_ft`, `oat_c`, `rpm`, `tps`, `tas_knots`, `flight_phase`.
  * Computes barometric pressure $P_{\text{amb}}$, air density $\rho_{\text{amb}}$, manifold pressure $\text{MAP}_{\text{exp}}$, air mass flow, target AFR, thermal equilibrium CHT, and oil pressure.
  * Output: `expected: EnginePhysicalState`.

---

### Step 3: Residual Vector Calculation & Channel Normalization
* **Caller:** Stage 2 & Stage 5 of `DetectionPipeline.process_frame()`.
* **Action:** Calls `RotaxThermoModel.compute_residuals(actual, expected)`:
  * Generates 14 physical deltas: $\Delta \text{CHT}_i$, $\Delta \text{EGT}_i$, $\Delta \text{OilPress}$, $\Delta \text{OilTemp}$, $\Delta \text{FuelFlow}$, $\Delta \text{MAP}$, $\Delta \text{VibRMS}$, $\Delta \text{BusVoltage}$.
* **Channel Score Normalization:**
  ```python
  channel_scores = {
      "d_CHT_1": min(1.0, abs(residuals.d_CHT_1) / 15.0),
      "d_CHT_2": min(1.0, abs(residuals.d_CHT_2) / 15.0),
      "d_CHT_3": min(1.0, abs(residuals.d_CHT_3) / 15.0),
      "d_CHT_4": min(1.0, abs(residuals.d_CHT_4) / 15.0),
      "d_EGT_1": min(1.0, abs(residuals.d_EGT_1) / 60.0),
      "d_EGT_2": min(1.0, abs(residuals.d_EGT_2) / 60.0),
      "d_EGT_3": min(1.0, abs(residuals.d_EGT_3) / 60.0),
      "d_EGT_4": min(1.0, abs(residuals.d_EGT_4) / 60.0),
      "d_OIL_PRESS": min(1.0, abs(residuals.d_OIL_PRESS) / 2.0),
      "d_OIL_TEMP": min(1.0, abs(residuals.d_OIL_TEMP) / 20.0),
      "d_FUEL_FLOW": min(1.0, abs(residuals.d_FUEL_FLOW) / 6.0),
      "d_MAP": min(1.0, abs(residuals.d_MAP) / 10.0),
      "d_VIB_RMS": min(1.0, abs(residuals.d_VIB_RMS) / 2.5),
      "d_BUS_VOLTAGE": min(1.0, abs(residuals.d_BUS_VOLTAGE) / 2.0),
      "__composite__": composite_score,
  }
  ```

---

### Step 4: Buffer Ingestion & Thread Decoupling
* **Action:** Calls `self._buffer.append(now, composite_score, channel_scores)`.
* **Data Structure:** `ScoreBuffer` (`backend/ml/trend_analyser.py`) holds a circular deque of maxlen 7,200 tuples: `(timestamp_sec, composite_score, channel_scores_dict)`.
* **Threading Guarantee:** Appending acquires `self._lock` for $< 1\text{ }\mu\text{s}$, completely isolating high-speed flight control from background regression math.

---

### Step 5: Multi-Window Slicing (Thread 2 — Every 20 Seconds)
* **Caller:** `PrognosticsWorker._run_loop()` -> `_analyse_and_update()`.
* **Action:** Calls `self._buffer.snapshot()` to safely clone recent frames.
* **Slicing Logic:** In `DegradationTrendAnalyser.analyse()`:
  * Evaluates three windows: `short` (120 s), `medium` (600 s), `long` (1800 s).
  * Filters points: `window_points = [(t, s) for t, s in points if current_t - t <= wsec]`.
  * Converts time to minutes: `ts_min = [t / 60.0 for t, _ in window_points]`.

---

### Step 6: Candidate Model Fitting
* **Action:** Executes three candidate regression functions on each window subset:
  1. `_least_squares_linear(ts_min, ys)` -> `(a_l, b_l, r2_l)`
  2. `_fit_exponential(ts_min, ys)` -> `(a_e, b_e, r2_e)` (filters $y > 10^{-6}$)
  3. `_fit_power_law(ts_min, ys)` -> `(a_p, b_p, r2_p)` (filters $t > 0, y > 0$)

---

### Step 7: Akaike Information Criterion (AIC) Selection
* **Action:** Computes AIC for each fitted candidate:
  $$\text{AIC} = n \cdot \ln\left(\frac{\text{SSE}}{n}\right) + 2k \quad (k = 2)$$
* **Selection:** Picks the candidate with the lowest AIC score within each window. Across all windows, selects the window with the highest $R^2 \ge 0.55$ and positive slope ($\text{drift\_rate} > 0.0002/\text{min}$).

---

### Step 8: Time-to-Breach Binary Search Projection
* **Action:** Calls `self._time_to_breach(best_model, t_now_min, current_score, fault_threshold)`.
* **Thresholds:** Looked up from `FAULT_THRESHOLD_SCORE` (e.g., $0.75$ for `d_CHT_2`, $0.80$ for `d_OIL_PRESS`).
* **Bisection Algorithm:** 40 bisection iterations over $[t_{\text{now}}, t_{\text{now}} + 480.0\text{ min}]$ solving $\hat{y}(t_{\text{breach}}) = \text{Threshold}$.
* **Output:** `time_to_threshold_min` (e.g., $42.0\text{ min}$).

---

### Step 9: Monte Carlo Uncertainty Sampling
* **Caller:** `ProbabilisticRULEstimator.estimate(trend_report, component)`.
* **Action:** Samples 500 parameter perturbations:
  $$\sigma_b = \frac{1.0 - R^2}{\sqrt{n}} \cdot 2.0, \quad b_{\text{perturbed}} = b \cdot (1 + \mathcal{N}(0, \sigma_b))$$
* **Percentile Extraction:**
  * `p10 = times[int(0.10 * n_t)]` (Conservative lower bound -> Go/No-Go decision)
  * `p50 = times[int(0.50 * n_t)]` (Median expected life)
  * `p90 = times[int(0.90 * n_t)]` (Optimistic upper bound)

---

### Step 10: Downstream Packaging & WebSocket Broadcast
* **Action in `engine_service.py`:**
  ```python
  if prog and prog.channels_with_trends:
      tr = prog.channels_with_trends[0]
      if tr.alert_level != "NOMINAL" and math.isfinite(tr.time_to_threshold_min):
          early_trend = {
              "channel": tr.channel,
              "drift_rate_per_hr": tr.drift_rate_per_min * 60.0,
              "time_to_threshold_min": tr.time_to_threshold_min,
              "alert_level": tr.alert_level,
              "message": f"Sub-threshold drift detected in {tr.channel} ({tr.drift_rate_per_min*60:+.2f}/hr)"
          }
  ```
* **Payload Serialization:** Injected into `UnifiedTelemetryState.analytics.early_warning_trend` and pushed over `ws://127.0.0.1:8000/ws/telemetry`.
