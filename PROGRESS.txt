=== 19 Nov 2026  M0-04 Fault manager
backend/faults/manager.py: FaultManager (inject / clear / active / history, events FAULT_INJECTED / UPDATED /
  CLEARED / REJECTED with source) plus LegacyRuntimeAdapter, which drives the current EngineRuntime plant through
  plant_mode_legacy until backend/sim exists.
Edge cases covered (R 19.4):
  - invalid cylinder / severity / ramp / source / unknown id -> rejected with a reason and logged;
  - inapplicable fault -> rejected;
  - repeated request_id -> same fault;
  - same fault + place -> update, not duplicate;
  - clear one keeps the others (re-applied);
  - a fault the plant cannot simulate yet is accepted with simulated=False and announced, never dropped.
Known limitation (documented in code): the legacy plant cannot change one fault, so remaining faults are
  re-applied and their ramps restart. Removed when backend/sim replaces the plant (Phase 2).
