ANUMAAN (SIH PS-26054) - 3D COMPONENTS AND FAULT HIGHLIGHTING ADDENDUM
Follow-up to ANUMAAN_AUDIT_REPORT.txt (the version already shared with the team).
Date: 18 Nov 2026. Branch audited: main, commit 9b5942e. No project file was changed.

This document completes the "components" part that was left short in the earlier report (sections 22, 23 and 27).
It gives, for every engine, the exact list of 3D components that exist today (checked against the real model
files), the components that are missing, how to add them, which components every fault must highlight on every
engine, and how to wire it so the same parts light up no matter where the fault is injected.


1. HOW THIS WAS CHECKED

A read-only script opened each engine model used by the 3D window (apps/threejs_twin/assets/models/draco/*.glb),
read every mesh node name, grouped the nodes into proposed components with name patterns, and reported:
- how many model nodes belong to each component,
- which components do not exist in the model (MISSING),
- which model nodes were not assigned to any component (UNASSIGNED).
Result summary:
  Rotax 912 iS : 106 nodes -> 17 components exist, 40 needed components missing, 0 unassigned.
  Rotax 914    : 590 nodes -> 13 components exist (2 of them unreliable), 36 missing, 0 unassigned.
  Rotax 915 iS : 15 nodes  -> 11 components exist (1 is the whole engine merged), 40 missing, 0 unassigned.
  Austro AE300 : 163 nodes -> 69 components exist, 3 missing (radiator, thermostat, VGT actuator), 0 unassigned.
  VRDE 2.2 L   : 426 nodes -> 67 components exist, 3 missing (radiator, airbox/filter, ECU), 2 unassigned
                 (Crank_Sensor_Wire_1/2 - belong to sensor_crank_1/2).
Conclusion: the two diesel models are ready for full per-part and per-cylinder highlighting today. The three Rotax
models need Blender work before most faults can highlight the right part.


2. CORRECTIONS TO SECTION 27 ("FAST FIX") OF THE EARLIER REPORT

2.1 Rotax 914 cylinder heads: section 27 said "rename cylinder heads to Cylinder_Head_1..4 by position". The model
    check shows the names do not mean what they say:
      Rotax914_Cylinder_Bank_1  is about 244 x 144 x 162 units - it spans BOTH cylinders on one side of the boxer.
      Rotax914_Cylinder_Head_4 and _5 are about 122 units wide - single barrels on the other side.
      Rotax914_Cylinder_Head_2 and _3 are about 208 x 90 units and sit higher (y = 102.8) - probably head covers or
      heads spanning two cylinders.
    So the names cannot be trusted. Open the file in Blender, identify each object visually, then split/rename.
    Do not rename by position alone.
2.2 Rotax 914 "wastegate" (320 objects): median object size is about 9 units, only 26 objects are larger than 50
    units. Most of the 320 are small fittings, clamps and bolts wrongly labelled. Reassign them by looking at them
    in Blender (small ones -> fasteners/plumbing; large ones -> exhaust, turbo, wastegate). Only the real wastegate
    and its actuator may keep the wastegate name.
2.3 Rotax 912: every physical part is split into several objects by material (for example the ECU is 20 objects,
    the base engine 21 objects). A component must therefore list SEVERAL node names. Exact-name matching is still
    the rule, but the manifest stores the full list of exact names (generated once from the patterns in section 3).
2.4 Draco files: the compressed Rotax 912 file in frontend/public/models has 109 nodes, the uncompressed one used by
    the 3D window has 106. They are different exports. Regenerate all web files from the fixed .blend files with one
    export script; do not mix the two old exports.
2.5 Section 27 said the AE300 and VRDE "can be filled completely today" - confirmed, except radiator, thermostat
    (AE300), VGT actuator (AE300), airbox/filter and ECU (VRDE), which do not exist in those models.

4. BLENDER WORK LIST TO ADD THE MISSING COMPONENTS (Blender 5.2 at D:\Blender\blender.exe)

General rules for all engines
- Work on the master .blend per engine (assets/blender/<engine>.blend); delete duplicate copies afterwards
  (rotax_915.blend == rotax_915is.blend; three 914 copies).
- Naming: one object (or one empty with child objects) per component, named exactly <component_id> from section 3,
  per-cylinder ones with the cylinder number (cylinder numbering must follow the manufacturer's numbering - check the
  Rotax/Austro installation drawings: Rotax 912/914/915 cylinders 1-4 with 1/3 on one side and 2/4 on the other).
- Add a custom property component_id on every component object (exported to glTF "extras" when "Include > Custom
  Properties" is on).
- Material-split meshes (912): keep the material objects but parent them under one empty named after the
  component; the manifest lists all child node names.
- Placeholder parts are allowed where real geometry is missing (a simple, correctly placed and sized shape with a
  neutral material) - far better than lighting the whole engine. Mark them with custom property placeholder=true so
  they can be replaced later.
- After editing: apply transforms, check normals, export with modifiers applied, then run the asset test (section 8).

Rotax 912 iS
1. Separate the merged base (Rotax_912i_Base_*, 21 objects) into: crankcase, cylinder_barrel_1..4,
   cylinder_head_1..4, intake_manifold, using Edit Mode > Separate > By Loose Parts, then join pieces per component
   and rename. Each piece must keep its material.
2. Add placeholders (if geometry is not inside the base): injector_1..4 + fuel_rail (on the intake side of each
   head), spark_plug_1..4 and ignition_coil_1..4 (two plugs per cylinder exist on Rotax; one placeholder per
   cylinder is enough for highlighting), airbox_filter, oil_pump, oil_cooler, radiator, water_pump, prop_flange,
   sensor_cht_1..4 (on each head), sensor_egt_1..4 (on each exhaust pipe near the head), sensor_oil_press,
   sensor_oil_temp, sensor_map, sensor_coolant_temp.
3. Parent the existing material-split objects of each existing component (ECU 20 objects, Water_Hoses 7, etc.)
   under one empty per component.

Rotax 914
1. Inspect Rotax914_Cylinder_Bank_1 and Rotax914_Cylinder_Head_2..5 visually; split and rename into
   cylinder_barrel_1..4 and cylinder_head_1..4 with correct cylinder numbers (see correction 2.1).
2. Reassign the 320 Rotax914_Turbo_Wastegate_* objects: select by size (small ones -> fasteners/plumbing), check the
   26 large ones individually (exhaust, turbo housing, wastegate, actuator). Only the true wastegate keeps the name.
3. Add placeholders: carburettor_1, carburettor_2 (the 914 is carburetted), airbox_filter, tcu, wastegate_actuator,
   oil_tank, oil_pump, oil_cooler, radiator, water_pump, alternator, fuel_pump, ignition_cdi, spark_plug_1..4,
   sensor_cht_1..4, sensor_egt_1..4, sensor_oil_press, sensor_oil_temp, sensor_map.

Rotax 915 iS
1. "Main engine" (one object, 114 material parts): Separate > By Material first (it already has the material split
   in its primitives), then By Loose Parts, then join and rename into crankcase, cylinder_barrel_1..4,
   cylinder_head_1..4, turbocharger, wastegate, intake_manifold, exhaust, injector_1..4, fuel_rail, water_pump,
   coolant_hoses, alternator, prop_flange, sensors.
2. Rename the five CAD-id objects (5608_@OIS@_5081 etc.) after identifying them.
3. Add placeholders for anything that is not in the geometry (airbox_filter, oil_pump, oil_cooler, radiator,
   sensor_egt_1..4, sensor_cht_1..4, sensor_oil_press, sensor_map).

Austro AE300

2. Optional: split Cylinder_Head and Glow_Plugs per cylinder (cylinder_head_1..4, glow_plug_1..4).
