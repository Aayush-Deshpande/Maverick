# Project ANUMAAN — Documentation Site Content

This folder is the content baseline for the Project ANUMAAN documentation website.

## Primary site sections

1. **Technical Documentation**
2. **SIH Journey**

Research, validation, evidence, limitations, and the demo runbook live under Technical Documentation.

## Content principles

- Document the implementation as it exists, not as a future architecture unless explicitly marked as **Roadmap**.
- Every important technical claim should have an **Evidence** or **Source** note.
- Distinguish **implemented**, **partially implemented**, **simulated**, and **planned** capabilities.
- Prefer engineering explanations over marketing language.
- Use Mermaid for system diagrams.
- Diagrams should be monochrome / neutral and visually close to an Excalidraw-style engineering sketch.
- Avoid fake screenshots, fabricated metrics, and invented SIH timeline events.
